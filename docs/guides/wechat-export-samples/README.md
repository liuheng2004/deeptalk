# 微信导出样例

本目录存放微信「邮件发送聊天记录」导出的 txt 样例，用于 `core/parser` 的开发与测试。所有样例均为**人工拟写的脱敏示例**，并非真实聊天记录，可自由用于测试。

## 格式说明

样例严格遵循 [`../parser-spec.md`](../parser-spec.md) 中定义的规范格式：文件首部为可选的元信息头（以空行结束），其后为消息块流，块之间以单个空行分隔。每个消息块由「时间行 + 内容行」构成；当时间行缺失时由解析器按推断策略补全（详见规范文档）。

## 样例清单

| 文件 | 场景 | 覆盖特性 |
|------|------|----------|
| `sample-01-basic-daily.txt` | 日常问答 | 时间行、昵称、纯文本、多行内容、撤回系统消息（无时间行） |
| `sample-02-rich-features.txt` | 面试抉择 | 语音转文字(voip_text)、引用回复(quote)、拍一拍系统消息、跨天、连续同发言人省略时间行 |
| `sample-03-multiline-edge.txt` | 久未联系 | 多行消息、连续同发言人省略时间行、撤回、跨多天 |

## 脱敏说明

样例为人工拟写，不存在真实个人信息；为模拟真实导出又兼顾隐私，以下占位符规则统一适用：

- **昵称**：双方昵称均为虚构占位符。本机账号统一记为「林深」（导出原文），解析后按规范映射为 `me`；对方分别为「星河」「晨曦」「远舟」。
- **手机号 / 联系方式**：以 `[手机号]` 占位。
- **地名**：城市、地点、地铁站以 `[城市名]`、`[地点]` 表示。
- **机构名**：公司、酒店等以 `[公司名]`、`[酒店名]` 占位。

## 与契约的关系

样例仅作为解析器输入的参考；解析器输出须符合 [`../../contracts/session.schema.json`](../../contracts/session.schema.json)。样例中的「消息条数」字段为微信导出的统计值，**仅供参照**，解析器以实际解析条数为准（见规范文档「边界与异常处理」）。
