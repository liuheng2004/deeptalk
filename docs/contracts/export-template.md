# 导出模板规范

> 定稿状态:初稿,待 CodeBuddy 评审。

## 通用规则

- 支持三种格式:图片(PNG)/ PDF / Markdown(MD);
- 水印:PNG 默认右下角半透明「DeepTalk」水印,设置可关闭;PDF 封面带 logo、页脚小字;MD 只写头部元数据,不插图;
- 所有导出必须包含时间信息:日期(含星期)、起止时间、持续时长、距今(如「2 年前的今天」);
- 分享隐私:默认隐藏敏感字段,用户可手动开启显示昵称 / 评分。

## PNG(分享卡片)

- 尺寸:1080 × 1440(3:4,朋友圈友好);
- 版式(自上而下):
  1. 顶部:日期 + 距今;
  2. 中部:主题标签 + 金句(1-2 条,大字);
  3. 底部:对方昵称、深度评分、DeepTalk 水印(右下角);
- 背景:由深度评分决定氛围色(高价值暖色 / 普通灰色渐变)。

## PDF(存档文档)

- 页面:A4;
- 结构:封面(logo + 标题 + 时间)→ 对话摘要 → AI 第三方回应 → 完整对话逐条排版;
- 页脚:DeepTalk 小字标注 + 页码。

## Markdown(可迁移笔记)

- 使用 YAML front matter 写入元数据,便于 Obsidian 检索:

```yaml
---
title: 深夜长谈:关于未来的选择
date: 2024-05-20
peer: 某某
score: 87
tags: [深夜emo, 职业选择]
session_id: xxx
---
```

- 正文:标题 → 摘要 → AI 回应 → 完整对话(按时间倒序或正序)。
