# 完整剪影版影子回放 · 动效原型 (SMOKE-BUDDY)

单文件 HTML 原型：两张剪影人物相对而立，对话气泡按**消息时间戳间隔**依次浮现 / 消散，节奏完全由数据驱动（不写死）。

## 运行方式

无需构建、无需依赖，直接用浏览器打开即可：

```bash
# 方式一：双击文件
open src/prototypes/shadow.html        # macOS
# 或在文件管理器中双击该文件

# 方式二：本地起一个静态服务（可选）
python3 -m http.server 8080
# 然后访问 http://localhost:8080/src/prototypes/shadow.html
```

> 推荐用 Chrome / Edge / Firefox 等现代浏览器打开。

## 交互说明

| 控件 | 作用 |
|------|------|
| 样例下拉框 | 切换 **A · 深夜长谈**（间隔疏密不均）与 **B · 清晨快聊**（节奏紧凑）两组时间戳。气泡浮现的疏密节奏会随之变化——这是数据驱动的核心验收点。 |
| 循环滑块 | 调整单次循环时长，范围 **3–5 秒**（默认 4.0s）。真实消息间隔会被等比缩放到该窗口内，间隔比例保持不变。 |
| 减弱动效 | 切换 `.reduced` 样式：关闭人物呼吸 / 起伏动画，气泡改为快速淡入淡出（样式示意）。也会自动尊重系统的「减少动态效果」系统偏好。 |
| 重播 | 立即重新开始当前循环。 |

## 设计要点

- **数据驱动节奏**：`buildSchedule()` 读取每条消息的 `t`（时间戳），计算相邻消息的真实间隔，再按 `loopDuration` 等比缩放映射到 3–5s 循环窗口。改数据即改节奏，代码里没有任何硬编码的延时常量。
- **剪影**：左右两个 SVG 剪影（我方蓝 / 对方橙），说话时短暂加速「呼吸」起伏。
- **气泡**：按 `from` 字段归位到对应一侧，浮现后存活其间隔的 70% 再消散，因此同侧不会重叠。
- **水印**：右下角半透明「DeepTalk」水印，参考 `docs/contracts/export-template.md` 的导出规范。

# WebGL 进入动画原型 (splash-gl.html)

单文件 HTML 原型：全屏 WebGL 单 shader 氛围（暖色渐变 + logo 光晕），无粒子、低功耗，总时长 3.2s。

## 运行方式

浏览器直接打开 `src/prototypes/splash-gl.html` 即可（零依赖）。

## 设计约束（均已实现）

- 时长 2~4s（默认 3.2s），到点自动退出；
- 退出后销毁 rAF / 定时器 / resize 监听 / GL 上下文，动画期外零开销；
- 像素比封顶 1.5，关闭 antialias / depth / stencil / preserveDrawingBuffer；
- 尊重系统 `prefers-reduced-motion`：只画一帧静态画面、不跑动画循环、时长缩至 1.2s；
- 点击 / 回车 / 空格可跳过；
- 左下角「减弱动效」开关，localStorage 持久化（`deeptalk:reducedMotion`）；
- WebGL 不可用时自动降级为纯 CSS 渐变（不黑屏）；
- 退出后提供「重新播放进入动画」按钮便于反复预览。

- `splash-gl.html` — 原型本体（内联 CSS/JS，自包含）。
